# Quick Guide: Push to GitHub

## Step 1: Create GitHub Repository

1. Go to https://github.com/new
2. Repository name: `northline` (or your preferred name)
3. Description: `A curated career marketplace - find work worth doing`
4. Choose: **Public** or **Private**
5. **Do NOT** initialize with README, .gitignore, or license (we already have them)
6. Click "Create repository"

## Step 2: Initialize Git and Push

Open PowerShell in your project directory and run:

```powershell
# Navigate to project directory
cd c:\Users\DELL\Downloads\Northline

# Initialize git repository
git init

# Add all files
git add .

# Create initial commit
git commit -m "Initial commit: Northline job board migrated from Grok"

# Rename branch to main
git branch -M main

# Add your GitHub repository as remote (replace with your actual URL)
git remote add origin https://github.com/YOUR-USERNAME/northline.git

# Push to GitHub
git push -u origin main
```

## Step 3: Replace Remote URL

**Replace `YOUR-USERNAME` with your actual GitHub username:**

```powershell
git remote set-url origin https://github.com/YOUR-USERNAME/northline.git
```

Or if you prefer SSH:

```powershell
git remote set-url origin git@github.com:YOUR-USERNAME/northline.git
```

## Important Files to Verify Before Pushing

✅ These files should be committed:
- `.gitignore` - Version control exclusions
- `.env.example` - Environment template (safe to commit)
- `package.json` - Dependencies
- `package-lock.json` - Lock file for reproducible builds
- `README.md` - Project documentation
- `DEPLOYMENT.md` - Deployment guide
- All source code in `src/`

❌ These should NOT be committed (already in .gitignore):
- `.env` - Contains local environment variables
- `node_modules/` - Dependencies (will be installed via npm)
- `.output/` - Build outputs
- `.vercel/` - Vercel deployment cache
- `.grok/` - Old Grok files (delete manually first)
- `public/__grok/` - Old Grok assets (delete manually first)

## Before Pushing - Final Cleanup

Delete these directories manually if they still exist:

```powershell
# Check if they exist
if (Test-Path ".grok") { Write-Host "⚠️ .grok exists - DELETE IT" }
if (Test-Path "public\__grok") { Write-Host "⚠️ public\__grok exists - DELETE IT" }
if (Test-Path "server") { 
    $hasFiles = (Get-ChildItem "server" -Recurse).Count -gt 0
    if (-not $hasFiles) { 
        Write-Host "✅ server directory is empty - you can delete it"
    }
}

# Delete them
Remove-Item -Recurse -Force ".grok" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "public\__grok" -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force "server" -ErrorAction SilentlyContinue

Write-Host "✅ Cleanup complete!"
```

## After Pushing to GitHub

### Set up Vercel Deployment (Optional)

1. Go to https://vercel.com
2. Sign in with GitHub
3. Click "New Project"
4. Select your `northline` repository
5. Vercel will auto-detect settings from `vercel.json`
6. Add environment variables:
   - `VITE_AUTH_ENABLED` = `false`
   - `NODE_ENV` = `production`
7. Click "Deploy"

On your GitHub repository page:
- Click the gear icon next to "About"

## Useful Git Commands

```powershell
# Check status
git status

# View changes
git diff

# Add specific files
git add <filename>

# Commit changes
git commit -m "Your message"

# Push changes
git push

# Pull latest changes
git pull

# Create a new branch
git checkout -b feature-name

# Switch branches
git checkout main

# View commit history
git log --oneline

# Undo last commit (keep changes)
git reset --soft HEAD~1
```

## Troubleshooting

### Authentication Failed

Use personal access token instead of password:
1. Go to GitHub Settings → Developer settings → Personal access tokens
2. Generate new token (classic)
3. Select scopes: `repo`
4. Use token as password when pushing

### Already Exists Error

```powershell
# Force push (careful - only if you're sure)
git push -f origin main
```

### Large Files Warning

If you accidentally added large files:

```powershell
# Remove from git but keep locally
git rm --cached <large-file>

# Or use .gitignore to exclude them
echo "large-file" >> .gitignore
git add .gitignore
git commit -m "Ignore large files"
```
